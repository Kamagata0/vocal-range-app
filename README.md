# VocalAI (歌唱・音域分析＆AI練習Webアプリ)

「自分の声に合う曲を探せる」「歌唱練習を記録できる」「AIから練習アドバイスを受けられる」スマートフォン最適化Webアプリケーションです。

---

## 🎯 実装済み機能（フェーズ1＆一部フェーズ2先行実装）

1. **ホーム画面**
   - 「あなたの声に合う曲を見つけよう」
   - 登録音域のグラフィカルな帯バー表示（C2〜C6）
   - 音域サマリー（地声・裏声・カラオケ音名表記: mid1C, hiA等）
   - あなたの音域に合ったおすすめ曲ピックアップ
   - クイックアクセスボタン

2. **音域登録＆リアルタイムマイク音域測定**
   - 地声・裏声の最低音〜最高音の手動登録
   - Web Audio API（自己相関法）によるマイクリアルタイムピッチ検出
   - 発声中の音名（A4, C4など）およびカラオケ音名・周波数のリアルタイム表示
   - 測定された最高音・最低音のワンクリック音域反映

3. **曲検索＆音域相性自動判定**
   - 定番カラオケ曲の音域・難易度・練習タグデータベース
   - ユーザー音域との半音単位の比較・相性判定（「歌いやすそう」「やや高め」「高音練習向け」「裏声を活用すると歌いやすそう」「難易度高め」等）
   - 具体的な判定理由とおすすめキー調整（原キー / -2 など）
   - 曲ごとの練習ポイント解説

4. **練習記録＆成長グラフ**
   - 練習した曲・日付・練習時間・出せた最高音/最低音・課題・メモの記録
   - 記録ごとのAIアドバイス自動生成
   - Chart.jsによる最高音の成長推移グラフ（C5 → C#5 → D5...）

5. **AI歌唱トレーナー（チャット相談）**
   - 「裏声と地声がつながらない」「高音で喉が締まる」などのボイトレ相談
   - ユーザーの登録音域に合わせた具体的な練習方法（リップロール、ハミング、エッジボイス等）
   - 喉の痛み・声の異常に対する安全な医療配慮ガイダンス

---

## 🚀 起動方法

### 方法1：バッチファイルをダブルクリック
フォルダ内の `run.bat` をダブルクリックするだけでブラウザが自動的に開きます。

### 方法2：コマンドラインから起動
```bash
python server.py
```
起動後、ブラウザで `http://localhost:8080` にアクセスしてください。
